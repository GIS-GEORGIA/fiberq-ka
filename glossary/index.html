    ლექსიკონი¶

    ინგლისური ტერმინი → ქართული → რას ნიშნავს FiberQ-ში.

    ძებნა ინგლისურ ტერმინზე

    ქართული lunr-ის ენების სიაში არ შედის, ანუ ძებნას სტემინგი არ აქვს — „ბოძი" ვერ იპოვის „ბოძის"-ს. ინგლისური ტერმინით ძებნა უფრო საიმედოა, და ისედაც ეს არის დარგის რეალური გასაღები.

    ორი ლექსიკონი, ორი დანიშნულება

    ეს გვერდი ქართულენოვანი სასწავლო ვერსიაა. Repo-ში ცალკე დევს GLOSSARY-ka.md — ინგლისურენოვანი, FiberQ-ის CONTRIBUTING.md-ის ფორმატში, upstream-ში გასაგზავნად. შიგთავსი იგივეა, აუდიტორია სხვა.

    ინფრასტრუქტურა¶

    English ქართული განმარტება
    Pole ბოძი საყრდენი, რომელზეც საჰაერო კაბელი ეკიდება
    Manhole საკაბელო ჭა (მოკლედ: ჭა) მიწისქვეშა სასინჯი კამერა მილების ტრასაზე. არა ლუქი — ის მხოლოდ სახურავია
    Duct / PE pipe მილი (მენიუში: PE მილი) მიწაში ჩაფლული მილი, Ø 40 მმ. ინგლისურში ორი სიტყვაა ერთი საგნისთვის
    Transition pipe გადასასვლელის მილი მსხვილი დამცავი ფუტლარი (Ø 110 მმ) გზის/რკინიგზის/წყლის გადაკვეთაზე
    Ducting მილგაყვანილობა მთელი მილების ინფრასტრუქტურა: ჭები + მილები
    Trench თხრილი ღია გათხრა
    Route ტრასა ფიზიკური ტრასა მიწაზე. არა მარშრუტი, არა ფაილის path
    Routing ტრასირება ტრასის ხელსაწყოების ჯგუფი
    Breakpoint გაყოფის წერტილი ტრასის ხაზის გეომეტრიული ორად გაყოფა. არა ბოჭკოს დაზიანება
    Span მალი მონაკვეთი ორ საყრდენს შორის

    Cutting ჭრა ხაზოვანი ობიექტის გეომეტრიული გაყოფა

    მთავარი ხაფანგი

    QGIS-ის ქართული feature-ს თარგმნის როგორც ობიექტი. FiberQ-ის Object კი შენობაა.

    Feature → ობიექტი · Object → შენობა
